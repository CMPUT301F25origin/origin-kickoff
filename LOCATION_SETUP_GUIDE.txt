## Setup Instructions

### Step 1: Sync Gradle Dependencies
The following dependencies were added to `app/build.gradle.kts`:
```kotlin
implementation("com.google.android.gms:play-services-maps:18.2.0")
implementation("com.google.android.gms:play-services-location:21.1.0")
implementation("com.google.android.libraries.places:places:3.3.0")
```

**Action Required:**
1. In Android Studio, click: File → Sync Project with Gradle Files
2. Or run from terminal: `./gradlew build --refresh-dependencies`

### Step 2: Get Google Maps API Key (FREE)
Google Maps Platform has a generous free tier (28,000 map loads per month free).

**Get Your API Key:**
1. Go to: https://console.cloud.google.com/
2. Create a new project or select existing one
3. Enable these APIs:
   - Maps SDK for Android
   - Places API
4. Go to: Credentials → Create Credentials → API Key
5. Restrict the key to Android apps (add your package name and SHA-1 fingerprint)

**Get SHA-1 Fingerprint:**
Run in terminal:
```bash
cd /Users/gurmannnpreet/AndroidStudioProjects/origin-kickoff
./gradlew signingReport
```
Copy the SHA-1 from the debug keystore.

### Step 3: Add API Key to Project
Open: `app/src/main/res/values/strings.xml`

Replace this line:
```xml
<string name="google_maps_key">YOUR_GOOGLE_MAPS_API_KEY_HERE</string>
```

With your actual API key:
```xml
<string name="google_maps_key">AIzaSyC...</string>
```

### Step 4: Build the Project
After syncing Gradle and adding the API key:
```bash
./gradlew clean build
```

## How It Works

### User Flow:
1. **Create Event** → Tap "Location" field
2. **Location Search Screen** opens with two options:
   - Type to search locations (uses Google Places API)
   - Tap "Select custom location on map" for manual pin placement
3. **Select Location** from search results OR pick on map
4. **Location saved** with coordinates to Firestore

### Data Stored in Firestore:
```javascript
{
  "location": "123 Main St, Toronto, ON",  // Human-readable address
  "locationLatitude": 43.6532,              // Latitude coordinate
  "locationLongitude": -79.3832,            // Longitude coordinate
  "locationPlaceId": "ChIJ..."              // Google Place ID (optional)
}
```

## Troubleshooting

**If you see compilation errors:**
- Make sure you synced Gradle (File → Sync Project with Gradle Files)
- Clean and rebuild: Build → Clean Project, then Build → Rebuild Project

**If map doesn't load:**
- Check your API key is correct in strings.xml
- Verify you enabled "Maps SDK for Android" in Google Cloud Console
- Check AndroidManifest.xml has the meta-data for the API key

**If Places search doesn't work:**
- Verify you enabled "Places API" in Google Cloud Console
- Check API key restrictions allow your app's package name
